# Frontend rules: React components

React 19 + TypeScript, Tailwind 4, vendored shadcn. Imports use the aliases `@/` → `src/` and
`@/shadcn` → `src/shared/components/ui/shadcn` (configured in both `vite.config.ts` and
`vitest.config.ts`) — never write a deep relative path like `../../../shared/...`.

## Where a component belongs

- `features/firestore/pages/FirestorePage.tsx` (~2k lines) is the orchestrator. It owns query form
  state, selection, drawer/panel state, and preview drafts, and wires every dialog and panel.
- Everything under `features/firestore/components/**` (`dialogs/`, `layout/`, `query/`, `viewers/`)
  is presentational: it takes data and callbacks as props. Don't reach for server state or
  `useGcpStore` inside these — lift it to the page. A component that needs to stream should call
  `streamSse` with `firestoreContextHeaders(...)`, never build a request by hand (DUP-009).
- New shared primitives go in `shared/components/`. Files under `shared/components/ui/shadcn/` are
  vendored CLI output (style `radix-mira`, wired via `components.json`) — regenerate rather than
  hand-edit, and don't add project logic there.

## Routing

Routes are TanStack file-based under `src/routes/`. `src/routeTree.gen.ts` is generated by the Vite
plugin — **never edit it**, and don't import from it directly. `/` is a welcome page;
`/app/firestore` is the workspace.

## Connection state affects what you may render

A tab restored from localStorage is *not* attached to the backend. Before issuing requests, respect
`isTabAttached` / `markTabAttached` from `useGcpStore`; the re-init prompt is
`FirestoreReconnectNotice`. A component that fires a query against a detached tab produces a
confusing `IllegalStateException` from the server instead of a reconnect prompt.

## Rendering document values

Document fields arrive in the typed wire form (`{"integerValue": "42"}`), not as plain JSON. Use
`unwrapFirestoreValue` / `unwrapFirestoreFields` for display and `inferWireValue` /
`buildWriteFields` on the way back — see `.claude/rules/frontend/data-layer.md`. Don't
`JSON.stringify` a raw field and show it, and don't hand-write a `switch` over value kinds: read the
kind with `kindOf` and key off the `FirestoreValueKind` union, so a new kind is a compile error rather
than a silent `default:` (DUP-005).

## Errors surfaced to the user

Catch the typed errors the service layer throws — `FirestoreConflictError` (409, carries the latest
document for the conflict diff) and `FirestoreIndexError` (carries `indexUrl`) — and render their
specific affordance. Falling back to a generic toast for these two throws away the only information
the user can act on.
